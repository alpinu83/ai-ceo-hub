    EXAONE 키 대기 Gemini 무료 키 대기

    1. LG K-EXAONE 2.5 무료 API 키 (단순·한국어 업무)

    보유하신 엑사원 API 키를 넣으면 요약 · 초안 · 번역 · 코드 점검을 512K 무료 모델로 자동 처리합니다.

    EXAONE 콘솔 ↗

    2. Google Gemini 무료 API 키 (리서치·총괄)

    Google AI Studio 무료 키를 함께 넣으면 업무 분해 · 1차 리서치 · 회의실 대화가 2중 무료 체제로 가동됩니다.

    30초 무료 발급 ↗

    3. 무료 MCP 서버 2클릭 배포 (Meta Muse · Manus Cue 자동 연동 + 데이터 영구 백업)

    Render 무료 플랜으로 전용 HTTPS 서버(/api/mcp)를 띄우면 복사·붙여넣기 없이 Muse·Cue가 직접 업무를 가져가고, EXAONE/Gemini API도 CORS 제약 없이 안정적으로 실행됩니다. GITHUB_GIST_TOKEN만 추가하면 서버 재시작 시에도 데이터가 영구 보존됩니다.

    Render 무료 MCP 서버 원클릭 배포 ↗
